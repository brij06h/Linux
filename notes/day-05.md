# Linux Journey – Day 5: Linux Fundamentals

Today I learned the basics of Linux, its history, and some important concepts.

## User Interfaces

An **interface** is how a user communicates with a computer.

* **CUI (Character User Interface)** – Text-based interaction.
* **CLI (Command Line Interface)** – Users type commands in a terminal.
* **GUI (Graphical User Interface)** – Uses windows, icons, and buttons.

---

## DOS

**DOS (Disk Operating System)** was one of the earliest command-line operating systems for personal computers.

---

## UNIX

UNIX is a powerful multiuser and multitasking operating system that inspired many modern operating systems, including Linux.

---

## Kernel

The **kernel** is the core of an operating system.

It manages:

* Memory
* Processes
* Hardware devices
* File systems

---

## Open Source vs Closed Source

**Closed Source**

* Source code is private.
* Only the owner can modify it.

**Open Source**

* Source code is publicly available.
* Anyone can study, modify, and share it under its license.

---

## FSF & GNU

The **Free Software Foundation (FSF)** promotes software freedom and created the **GNU GPL** license.

**GNU (GNU's Not Unix)** is a free software project that developed many tools used with Linux, such as Bash and GCC.

---

## MINIX & Linux

* **MINIX** was created by Andrew S. Tanenbaum for educational purposes.
* **Linux** was created by Linus Torvalds in 1991.
* Linux itself is a **kernel**. Combined with GNU tools, it forms a complete operating system.

---

## What I Learned

* Linux is an open-source kernel.
* UNIX inspired Linux.
* The kernel is the heart of an operating system.
* GNU provides many tools that make Linux usable.
